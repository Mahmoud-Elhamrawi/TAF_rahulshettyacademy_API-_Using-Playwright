# Rahul Shetty Academy – API Automation Framework

An API Automation Testing Framework built using **Playwright with TypeScript** to automate and validate REST API workflows for the Rahul Shetty Academy E-Commerce application.

The framework focuses on API testing, request handling, dynamic test data, file uploads, response validation, and end-to-end API workflows.

## Tech Stack

- **Programming Language:** TypeScript
- **Automation Tool:** Playwright
- **Runtime Environment:** Node.js
- **Test Runner:** Playwright Test
- **Reporting:** Playwright HTML Reporter
- **API Testing:** Playwright APIRequestContext
